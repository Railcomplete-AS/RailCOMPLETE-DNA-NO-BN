Lua debugger

The Lua debugger is a powerful tool designed to help developers write Lua scripts in RailCOMPLETE. Whether you're building complex Lua scripts or simply troubleshooting issues, this debugger provides a range of features to simplify the debugging process.

Features at a Glance:

  1. Breakpoints: Set breakpoints in your Lua script to pause execution at specific lines of code for inspection.
  2. Variable Inspector: Examine the state of variables during execution to understand their values.
  3. Call Stack: Visualize the call stack to track function calls and their contexts.
  4. Watches: Monitor specific variables in real-time, enabling you to watch their values change as the program runs.
  5. Run: Execute your script until it completes or encounters a breakpoint.
  6. Step Into: Navigate into function calls to debug at a deeper level.
  7. Step Over: Execute the current line and move to the next one without stepping into function calls.
  8. Step Out: Finish executing the current function and return to the calling context.
  9. Pause: Temporarily halt the execution of your Lua script.
  10. Stop: Terminate the execution of the script entirely.

Enabling the debugger

The debugger is accessible in the large Lua editor window, such as from "RC-EDITSCRIPT" or "RC-QUERYOBJECT". To activate the debugger, check the debugger checkbox.

Notes

  • Only one script can execute at a time.
  • The Lua timeout function is disabled in debugging mode, as you can manually stop the script with the stop button.
  • If you're having trouble finding a specific variable in the variables tab, consider using a watch to have it easily accessible.
  • Tooltips are available for most of the features in the debugger, making it easier to understand their functionality.
  • Many actions within the debugger have convenient shortcuts, allowing for more efficient debugging.

Debugger Features

Breakpoints

Breakpoints are markers placed at specific lines in your Lua script where you want to pause execution for inspection.

Usage:

  • Click in the line number margin of the code window to toggle breakpoints or check shortcut by right clicking in the code editor.

Variable Inspector

The Variable Inspector allows you to inspect the values of variables at any point during script execution.

Usage:

  • Select a variable in the inspector to see its current value.
  • Expand tables and userdata to view their internal structure.

Note:

  • The type column displays the equivalent C# type of the variable, not the Lua type.

Call Stack

The Call Stack displays the sequence of function calls that led to the current execution point, helping you understand the program's flow.

Note:

  • When a function's last action is in the form of return function(args), Lua performs a tail-call optimization. Lua does not need to return to the function and removes it from the stack and call stack.

Usage:

  • Double-click on stack frames to navigate to the call frame's line.

Watches

Watches allow you to monitor the values of specific variables and evaluate expressions as the script executes, providing an easy way to monitor values without having to navigate the variables list. Watches with "break on change" checked will pause the script whenever the variable/expression returns a different value.

Usage:

  • Add variables to the watch list to monitor their values.
  • Watches can be suspended to conserve processing resources that might otherwise slow down execution speed.
  • Watches can be copied and pasted.

Note:

  • The watches are evaluated whenever the script pauses or for every line if "Break on change" is checked.
  • Watches are also evaluated immediately whenever the expression is changed and the script is paused.
  • Watches only have access to the variables available in the current evaluating scope.
  • If a global variable is not used or declared in the current scope, the watches will not have access to the global scope.
  • If an external local value is not used in the current scope, it will not be available.
  • Exercise caution with more complex watch expressions, as assignments and executing functions in watches may impact the script's state.

Run

The "Run" feature allows you to execute your script until completion, until a breakpoint is encountered or until a watch with break on change changed value.

Step Into

"Step Into" takes you inside function calls, allowing you to inspect and debug them.

Step Over

"Step Over" executes the current line and moves to the next, without entering function calls.

Step Out

"Step Out" lets you finish executing the current function and return to the calling context.

Pause

The "Pause" button halts script execution temporarily, allowing you to pause the script at any point.

Stop

The "Stop" button terminates the execution of your Lua script entirely.
